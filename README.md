# esp32-light-detect
基于ESP32的温度与灯光检测控制系统

## 项目功能
1. 光敏电阻采集环境光照，光线暗自动开启LED补光灯
2. DS18B20传感器采集温度，温度高于阈值自动开启风扇
3. 串口实时输出光照数值、温度、设备工作状态

## 硬件清单
- ESP32开发板
- 光敏电阻 + 10kΩ分压电阻
- DS18B20温度传感器 + 4.7kΩ上拉电阻
- LED灯、220Ω限流电阻
- 小风扇+三极管驱动模块

## 开发环境
Arduino IDE
依赖库：OneWire、DallasTemperature

## 引脚分配
光敏电阻：GPIO34
DS18B20：GPIO26
LED补光灯：GPIO27
风扇驱动：GPIO25
